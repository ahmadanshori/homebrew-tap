# Homebrew tap

```bash
brew install --cask ahmadanshori/tap/cleanori
```

| Cask | App |
|---|---|
| `cleanori` | [Cleanori](https://github.com/ahmadanshori/cleanori): a developer-focused disk cleaner for macOS |

Cleanori is not notarized by Apple: after installing, open it once, then click **Open Anyway** in
System Settings → Privacy & Security.
